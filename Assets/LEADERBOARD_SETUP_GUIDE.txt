STEP 1: ADD LEADERBOARD MANAGER TO SCENE
-----------------------------------------
1. In your Game scene, create an empty GameObject
   - Right-click in Hierarchy → Create Empty
   - Name it "LeaderboardManager"
   
2. Add the LeaderboardManager script
   - Select the LeaderboardManager GameObject
   - In Inspector, click "Add Component"
   - Search for "LeaderboardManager" and add it

3. Position it in your hierarchy (optional)
   - You can place it anywhere, but I recommend near GameManager
   - It will persist between scenes automatically

---------------------------------------
Navigate to: ---UI--- → Canvas → ClearScreenPanel

1. Create Gold Time Text:

     * Text: "🥈 --:--:---"

3. Create Bronze Time Text:
   - Right-click on ClearScreenPanel → UI → Text - TextMeshPro

STEP 3: ADD LEADERBOARD UI SCRIPT
----------------------------------
1. Create a GameObject to hold the script:
   - Right-click on ClearScreenPanel → Create Empty
   - Name it "LeaderboardUI"
   
2. Add the LeaderboardUI script:
   - Select the LeaderboardUI GameObject
   - Click "Add Component"
   - Search for "LeaderboardUI" and add it

3. Assign the text references in Inspector:
   - Drag GoldTimeText to the "Gold Time Text" field
   - Drag SilverTimeText to the "Silver Time Text" field
   - Drag BronzeTimeText to the "Bronze Time Text" field

4. (Optional) Customize colors:
   - Gold Color: RGB(255, 214, 0) - default
   - Silver Color: RGB(192, 192, 192) - default
   - Bronze Color: RGB(205, 127, 50) - default
   - Empty Color: RGB(128, 128, 128) - shown when no time recorded

STEP 4: CONNECT CLEARSCREEN TO LEADERBOARD
-------------------------------------------
1. Find the ClearScreen script in your scene
   - It should be attached to a GameObject (search for "ClearScreen" component)
   
2. In the Inspector, find the new fields added:
   - "Leaderboard UI" field (under Clear Screen Components)
   - "New Record Color" field (under Animation Settings)

3. Assign the LeaderboardUI reference:
   - Drag the LeaderboardUI GameObject from Step 3 to the "Leaderboard UI" field

4. (Optional) Customize the New Record Color:
   - Default is Yellow RGB(255, 255, 0)
   - This color is used for the congratulations text when you beat a record

HOW IT WORKS:
=============
1. When you complete the level, GameClear.cs calls ClearScreen.ShowClearScreen(time)
2. ClearScreen checks if the time is in the top 3:
   - If yes: Adds it to the leaderboard
   - Shows special message based on rank (🥇🥈🥉)
3. LeaderboardUI updates to display the current top 3 times
4. Times are saved to PlayerPrefs automatically
5. On next game start, times are loaded from PlayerPrefs

MEDAL MESSAGES:
- 🥇 NEW GOLD RECORD! = Fastest time (rank 1)
- 🥈 NEW SILVER RECORD! = 2nd fastest time (rank 2)
- 🥉 NEW BRONZE RECORD! = 3rd fastest time (rank 3)
- LEVEL COMPLETE! = Completed but not in top 3

TROUBLESHOOTING:
================
Q: Leaderboard not showing?
A: 1. Check that LeaderboardManager exists in the scene
   2. Verify LeaderboardUI reference is assigned in ClearScreen
   3. Check that all 3 text references are assigned in LeaderboardUI
   4. Look in Console for warnings/errors

Q: Times not saving between sessions?
A: 1. Check Console for PlayerPrefs errors
   2. Verify LeaderboardManager.Instance is not null
   3. Try Edit → Clear All PlayerPrefs and start fresh

Q: Special messages not showing?
A: 1. Complete the level again to add a time
   2. Check that your new time is actually in top 3
   3. Verify LeaderboardManager.Instance exists

Q: Button still not clickable?
A: 1. Check that RestartButton is assigned in ClearScreen Inspector
   2. Make sure EventSystem exists in scene (---INPUT---/EventSystem)
   3. Verify button "Interactable" is checked
   4. Look for "RestartGame listener added to button!" in Console

════════════════════════════════════════════════════════════════════════════

RESET LEADERBOARD:
==================
Option 1 - Use Debug Tool:
- Add LeaderboardDebugger to scene
- Press Shift + L during Play Mode

Option 2 - Manual:
- Unity Menu → Edit → Clear All PlayerPrefs
- WARNING: This clears ALL PlayerPrefs data!

Option 3 - Code:
LeaderboardManager.Instance.ClearLeaderboard();
