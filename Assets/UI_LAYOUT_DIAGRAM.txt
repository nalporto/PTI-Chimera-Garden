FONT SUGGESTIONS:
=================
- Use the same font as your other UI elements for consistency
- Recommended: Bold or SemiBold weight for the times
- Add outline/shadow for better readability if using on dark backgrounds


ANIMATION NOTES:
================
The leaderboard texts will:
- Appear AFTER the congratulations and time texts fade in
- Update when the UpdateLeaderboardDisplay() is called
- Remain visible with the restart button

To customize animation timing, adjust in ClearScreen:
- fadeInDuration
- textFadeDelay


EMOJI COMPATIBILITY:
====================
The medal emojis (🥇🥈🥉) should work in most fonts.
If they don't appear:
- Use TextMeshPro fonts (better emoji support)
- Or replace with text: "GOLD:", "SILVER:", "BRONZE:"
- Edit goldPrefix/silverPrefix/bronzePrefix in LeaderboardUI script
