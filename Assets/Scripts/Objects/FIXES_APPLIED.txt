⚠️ SE AINDA NÃO FUNCIONAR
════════════════════════════════════════════════════════════════

VERIFIQUE NO CONSOLE:

❌ "Room 'X' has 177 enemies"
   → Os ossos ainda têm Tag "Enemy"
   → Remova Tag dos children dos inimigos

❌ Nenhuma mensagem "Room cleared"
   → Verifique se matou TODOS os inimigos
   → Verifique referência roomManager no LockedDoorPanel

❌ "Pressione F" não aparece
   → Verifique Alpha = 0 no Canvas Group
   → Verifique referências no LockedDoorPanel
   → Verifique distância do painel

❌ Pressionar F não faz nada
   → Verifique se está PERTO do painel (< 3m)
   → Verifique se painel está AZUL (unlocked)
   → Veja Console se há erros

❌ Porta não abre
   → Verifique DoorAnimation.isLocked = TRUE inicialmente
   → Verifique Player está configurado no DoorAnimation
   → Verifique Interaction Point configurado
