🔍 TROUBLESHOOTING
════════════════════════════════════════════════════════════════

❌ DOOR DOESN'T OPEN WHEN PRESSING F
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE 1: Door Animator not assigned

CHECK:
□ DoorPanel_ParentDoor3 → Door Animator field
□ Should have "Porta3" assigned

FIX:
Drag Porta3 GameObject into Door Animator field

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE 2: Console shows error

ERROR: "Cannot open door - Door Animator not assigned!"

FIX:
1. Select DoorPanel_ParentDoor3
2. Find "Door Animator" field (NOT "Door Animation"!)
3. Drag Porta3 from Hierarchy
4. Save Scene

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE 3: Animation doesn't play

CHECK:
□ Porta3 has Animator component
□ Animator Controller = "Porta1.controller"
□ Animator is enabled
□ Parameter "IsOpened" exists (bool type)

FIX:
1. Select Porta3
2. Verify Animator component has controller
3. Window → Animation → Animator
4. Check "IsOpened" parameter exists
