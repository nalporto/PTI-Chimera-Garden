🔄 HOW IT WORKS
════════════════════════════════════════════════════════════════

FLOW:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Game starts → Door isLocked = TRUE
   → Door won't open even if player is near

2. Player kills all enemies
   → RoomManager fires onAllEnemiesKilled event

3. LockedDoorPanel receives event
   → Panel turns BLUE
   → State = Unlocked

4. Player walks to panel
   → "Pressione F" appears

5. Player presses F
   → LockedDoorPanel.OpenDoor() called
   → doorAnimation.Unlock() called
   → Panel turns GREEN

6. DoorAnimation.isLocked = FALSE
   → Update() starts checking player distance

7. Player walks near Interaction Point
   → Distance < 3 meters
   → Animator.SetBool("IsOpened", true)
   → Door animation plays!
