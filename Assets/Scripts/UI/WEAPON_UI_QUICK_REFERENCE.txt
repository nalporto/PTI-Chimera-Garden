💡 QUICK TIPS
════════════════════════════════════════════════════════════════

WEAPON SPRITES:
- Size: 256x128 pixels recommended
- Format: PNG with transparency
- Style: White/light silhouette on transparent
- Import as: Sprite (2D and UI)

BULLET LAYOUT:
- Horizontal Layout Group auto-arranges bullets
- Spacing of 3px creates clean look
- Max 30 bullets prevents overflow

LOW AMMO WARNING:
- Threshold of 3 creates urgency
- Text turns red automatically
- Bullets stay orange (only text changes)

ANIMATION:
- Smooth fade on weapon switch
- Slight scale effect for polish
- Speed of 5 feels responsive

🐛 COMMON ISSUES & FIXES
════════════════════════════════════════════════════════════════

"No bullets showing"
→ Check Bullet Icon Prefab is assigned
→ Make sure prefab exists in /Assets/Prefabs/UI/

"Weapon name wrong"
→ Check weapon names in Weapon Data array
→ Names should match: PISTOL, SMG, SHOTGUN

"Icon not showing"
→ Import sprites as "Sprite (2D and UI)"
→ Assign to Weapon Data array

"Bullets stacked vertically"
→ Add Horizontal Layout Group to container
→ Set Child Alignment: Middle Left

"Text not updating"
→ Check WeaponSwitching reference assigned
→ Path: /---PLAYER---/Cam/WeaponHolder
