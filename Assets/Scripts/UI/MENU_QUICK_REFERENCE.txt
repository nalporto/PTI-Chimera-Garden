🐛 COMMON ISSUES
════════════════════════════════════════════════════════════════

"Play button doesn't work"
→ Check Game Scene Name in MainMenuManager
→ Make sure Game scene is in Build Settings

"Sliders don't update values"
→ Check references in ConfigManager
→ Make sure Value Text objects are assigned

"Config panel stays visible"
→ Set ConfigPanel inactive in Hierarchy initially
→ MainMenuPanel should be active

"Buttons don't scale on hover"
→ Make sure EventSystem exists in scene
→ Check MenuButton script is attached

📝 CUSTOMIZATION TIPS
════════════════════════════════════════════════════════════════

Change button spacing:
- Select buttons, adjust Y positions
- Keep equal spacing for balance

Add your logo:
- Import logo as Sprite
- Create UI → Image
- Position above title

Change fonts:
- Import custom font (.ttf or .otf)
- Window → TextMeshPro → Font Asset Creator
- Assign to text objects

Add more settings:
- Duplicate slider structure
- Add new slider to ConfigManager script
- Wire up OnValueChanged event
