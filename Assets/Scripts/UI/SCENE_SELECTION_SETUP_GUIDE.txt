     🎮 TUTORIAL/LEVEL SELECTION - COMPLETE SETUP GUIDE
════════════════════════════════════════════════════════════════

This guide will help you add a scene selection panel to your main menu
so players can choose between Tutorial and First Level.

════════════════════════════════════════════════════════════════
PART 1: SETUP THE SCENES
════════════════════════════════════════════════════════════════

STEP 1: DUPLICATE THE GAME SCENE
────────────────────────────────────────────────────────────────
1. In Project window, go to /Assets/Scenes/
2. Right-click "Game.unity"
3. Select "Duplicate"
4. Rename it to "Tutorial.unity"

STEP 2: CLEAN UP TUTORIAL SCENE
────────────────────────────────────────────────────────────────
1. Open Tutorial.unity
2. DELETE these from Hierarchy:
   ✗ /---MAP---/FirstLevel_Map (and all children)
   ✗ /---IA---/Room1_enemies
   ✗ /---IA---/Room2_enemies
   ✗ /---IA---/Enemy_R (4)
   ✗ /---IA---/Enemy_R (6)
   ✗ /---IA---/Enemy_M (2)
   ✗ /---IA---/Enemy_M (3)
   ✗ /---SAMPLE---/ (optional - if not needed)

3. KEEP these (essential):
   ✓ /---PLAYER---
   ✓ /---POST-PROCESSING---
   ✓ /---INPUT---
   ✓ /---UI---
   ✓ /TutorialMAP

4. Save (Ctrl+S)

STEP 3: CLEAN UP GAME SCENE
────────────────────────────────────────────────────────────────
1. Open Game.unity
2. DELETE:
   ✗ /TutorialMAP (now in separate Tutorial scene)

3. Save (Ctrl+S)

STEP 4: ADD SCENES TO BUILD SETTINGS
────────────────────────────────────────────────────────────────
1. File → Build Settings
2. Add these scenes (in order):
   [0] MainMenu
   [1] Tutorial
   [2] Game

3. Click "Add Open Scenes" if they're not there
4. Drag to reorder if needed

PART 2: UPDATE MAIN MENU UI
════════════════════════════════════════════════════════════════

Open MainMenu.unity scene

STEP 5: CREATE SCENE SELECTION PANEL
────────────────────────────────────────────────────────────────

RIGHT-CLICK ON CANVAS → UI → Panel

NAME: SceneSelectionPanel

RECT TRANSFORM:
────────────────────────────────────────────────────────────────

Left: 0, Right: 0, Top: 0, Bottom: 0

────────────────────────────────────────────────────────────────

STEP 10: ADD MenuButton COMPONENT TO ALL BUTTONS
────────────────────────────────────────────────────────────────

FOR EACH BUTTON (TutorialButton, SkipButton, BackButton):

1. Select the button
2. Add Component → "MenuButton"
3. Settings:
   - Normal Color: RGB(242, 242, 230)
   - Hover Color: RGB(255, 255, 220)
   - Enable Scale Effect: ✓ checked
   - Hover Scale: 1.05

════════════════════════════════════════════════════════════════
PART 3: CONNECT MENUMANAGER SCRIPT
════════════════════════════════════════════════════════════════

STEP 11: UPDATE MENUMANAGER GAMEOBJECT
────────────────────────────────────────────────────────────────

1. In Hierarchy, select the "MenuManager" GameObject

2. In Inspector, find the MenuManager component

3. Assign these references:
   ┌─────────────────────────────────────────────────────────┐
   │ Main Menu Panel:      MainMenuPanel (drag from Hierarchy)
   │ Config Panel:         ConfigPanel (drag from Hierarchy)
   │ Scene Selection Panel: SceneSelectionPanel (NEW!)
   │
   │ Tutorial Scene Name:  Tutorial
   │ Game Scene Name:      Game
   └─────────────────────────────────────────────────────────┘

STEP 12: CONNECT BUTTON EVENTS
────────────────────────────────────────────────────────────────

A) PLAY BUTTON (in MainMenuPanel):
   ────────────────────────────────────────────────────────────
   1. Select PlayButton in Hierarchy
   2. In Button component, find "On Click ()" event
   3. Click the "+" button
   4. Drag MenuManager GameObject into the object field
   5. Select: MenuManager → OnPlayButtonClicked()

B) TUTORIAL BUTTON (in SceneSelectionPanel):
   ────────────────────────────────────────────────────────────
   1. Select TutorialButton
   2. On Click () → Click "+"
   3. Drag MenuManager
   4. Select: MenuManager → OnStartTutorialClicked()

C) SKIP BUTTON (in SceneSelectionPanel):
   ────────────────────────────────────────────────────────────
   1. Select SkipButton
   2. On Click () → Click "+"
   3. Drag MenuManager
   4. Select: MenuManager → OnSkipToLevelClicked()

D) BACK BUTTON (in SceneSelectionPanel):
   ────────────────────────────────────────────────────────────
   1. Select BackButton
   2. On Click () → Click "+"
   3. Drag MenuManager
   4. Select: MenuManager → OnBackToMainMenuClicked()

STEP 13: SET INITIAL PANEL STATES
────────────────────────────────────────────────────────────────

In the Hierarchy:
   ✓ MainMenuPanel → Active (✓ checked)
   ✗ ConfigPanel → Inactive (uncheck)
   ✗ SceneSelectionPanel → Inactive (uncheck)

════════════════════════════════════════════════════════════════
PART 4: TEST YOUR SETUP
════════════════════════════════════════════════════════════════

1. Save all scenes (Ctrl+S)

2. Open MainMenu scene

3. Press Play

4. TEST FLOW:
   MainMenu → Click PLAY
   → Scene Selection appears
   → Click "START TUTORIAL" → Loads Tutorial scene
   
   OR
   
   MainMenu → Click PLAY
   → Scene Selection appears
   → Click "SKIP TO LEVEL 1" → Loads Game scene

5. Test "BACK" button returns to main menu
