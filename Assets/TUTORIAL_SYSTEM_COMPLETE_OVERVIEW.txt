📝 EXAMPLE: ADDING A TUTORIAL PROMPT
════════════════════════════════════════════════════════════════

Let's add a prompt that teaches movement:

1. Open Tutorial.unity

2. Create prompt trigger:
   - Right-click /---Tutorial_MAP---
   - Create Empty → Name: "Prompt_Movement"

3. Add Box Collider:
   - Add Component → Box Collider
   - Is Trigger: ✓
   - Size: 10, 5, 10 (adjust as needed)

4. Add Tutorial Prompt:
   - Add Component → TutorialPrompt
   - Prompt Message: "Press W, A, S, D to move around"
   - Display Duration: 3
   - Trigger Once: ✓

5. Create UI (if you haven't already):
   - In Canvas, create Panel: "TutorialPromptPanel"
   - Add CanvasGroup component
   - Add child TextMeshProUGUI: "PromptText"

6. Connect references:
   - Drag PromptText to TutorialPrompt's "Prompt Text"
   - Drag CanvasGroup to "Prompt Canvas Group"

7. Position trigger where player spawns

Done! Now when the player enters that area, they'll see the prompt.

════════════════════════════════════════════════════════════════
❓ TROUBLESHOOTING
════════════════════════════════════════════════════════════════

PROBLEM: Scene selection panel doesn't show
FIX: - Check MenuManager has SceneSelectionPanel assigned
     - Check panel is set to INACTIVE initially
     - Check OnPlayButtonClicked is connected to Play button

PROBLEM: Tutorial doesn't auto-skip after completion
FIX: - Check "Auto Skip Tutorial If Completed" is enabled
     - Check TutorialCompletionZone has "Mark Complete" enabled
     - Try Tools → Tutorial Setup Helper → Check status

PROBLEM: Completion zone doesn't trigger
FIX: - Check Player tag is set to "Player"
     - Check Box Collider "Is Trigger" is checked
     - Check zone is big enough and positioned correctly
     - Check layer collision matrix allows trigger

PROBLEM: Prompts don't appear
FIX: - Check UI references are assigned
     - Check CanvasGroup alpha is being controlled
     - Check trigger colliders are positioned on player path
     - Check Canvas is in Screen Space - Overlay mode

PROBLEM: Wrong scene loads
FIX: - Check scene names match EXACTLY (case-sensitive)
     - Check scenes are in Build Settings
     - Check indices in Build Settings are correct
